¿Para qué servirá HTML?

Para definir la estructura de la página web. Ej:

<h1>Rueda libre</h1>

¿Para qué servirá CSS?

Para darle estilo a los diferentes elementos del sitio web. Ej:

h1 {
    font-size: 32px;
}

¿Para qué servirá JavaScript?

Para darle funcionalidades extra al sitio web. Ej:

const title = document.querySelector("h1");
title.addEventListener("mouseenter", () => title.style.scale = "1.1");
title.addEventListener("mouseleave", () => title.style.scale = "1");

Justificación de uso de los controladores:

Para el nombre usé un controlador tipo 'text' porque considero que es un texto plano.
Para la fecha del alquiler usé tipo 'date' para que el cliente pueda seleccionar una fecha.
Para el tipo de bicicleta usé una etiqueta 'select' porque el cliente debe elegir entre las diferentes opciones predefinidas.
